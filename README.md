# AIM:
To explore the fundamentals of User Interface (UI) and User Experience (UX), differentiate UI and UX using real-world examples, understand their relationship in the design process, and demonstrate various UI/UX design tools.

# PROCEDURE:
1. Understand the basic concepts of UI and UX and identify their roles in digital product design.
2. Differentiate UI and UX based on their purpose, components, and user interaction using real-world examples.
3. Study the relationship between UI and UX, understanding how UX focuses on the overall user experience while UI focuses on the visual and interactive elements.
4. Select a real-world application or website such as Instagram, Netflix, Amazon, or a food-ordering application for analysis.
5. Identify UI elements such as buttons, icons, colours, typography, navigation bars, cards, forms, and menus.
6. Identify UX aspects such as usability, navigation, accessibility, user flow, feedback, and ease of interaction.
7. Explore different UI/UX design tools such as Figma, Canva, Adobe XD, and Sketch.
8. Create a basic interface design using Figma or Canva, incorporating appropriate UI elements and design principles.
9. Create a simple user flow/prototype to demonstrate how users interact with the interface.
10. Compare the designed interface with the selected real-world example and identify how UI and UX principles are applied.
11. Review and evaluate the final design based on usability, consistency, accessibility, and visual appearance.
